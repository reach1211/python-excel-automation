# python-excel-automation

### 【概要】  
このツールは、複数のExcelファイルを読み込み、  
データの結合・整形・集計を自動で行うPythonスクリプトです。  

### 【使用技術】  
- Python  
- pandas  
- openpyxl  

### 【機能】  
- Excelファイルの読み込み  
- データの結合  
- 条件による抽出  
- 集計結果の出力  

### 【使い方】  
１. sampleフォルダにExcelファイルを配置  
２. main.py を実行  
３. output.xlsx が生成されます  

### 【想定利用シーン】  
- 売上データの月次集計  
- 手作業で行っていたExcel業務の自動化
